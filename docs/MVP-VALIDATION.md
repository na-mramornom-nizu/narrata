## Что исправлено и упрощено

- Удалены вымышленные демо-графики и дублирующая локальная сухая сводка. Отсутствие AI-ключа теперь вызывает ошибку подключения.
- Удалена слабая ветка `sanitize`, принимавшая непроверенные значения графиков текстового отчёта. Её заменил небольшой модуль валидации `text-analysis.ts`.
- Числа текстовых графиков связываются с исходными фрагментами; нечисловые категории не превращаются в временную ось. Отклоняются списки вместо нарратива, неподтверждённая равномерность и неправильные проценты.
- Сужен набор фактов для одного нарратива: отдельные группировки не должны превращаться в несуществующую совместную группу. Дополнительная числовая разница рассчитывается кодом.
- Исправлена обработка таймаута GigaChat, проверяется фактический UTF-8-размер запроса до отправки. Приветствие без фактов даёт понятное пустое состояние.
- Next.js обновлён до 15.5.27, SheetJS — до официальной 0.20.3, PostCSS — до 8.5.29. Для PostCSS зафиксирована единая исправленная версия.
- Удалён `rejectUnauthorized: false`. Сертификат получен по HTTPS из официального источника, используется локально клиентом GigaChat и включён в serverless-сборку. Реальный запрос с проверкой TLS успешен.
- Неработавшая команда `next lint` без ESLint-конфигурации заменена честной `npm run typecheck`; новый линтер ради галочки не добавлялся.

## Что намеренно сохранено

PDF и расширенные вычисления выходят за минимальный текст задания, но ранее были прямо запрошены владельцем проекта. Их удаление было бы регрессией. SQLite работает в памяти отдельного worker только для чтения и не превращает проект в отдельный сложный бэкенд. Ограничения времени, памяти, результатов и запрет произвольного выполнения кода сохранены.

## Ограничения и остаточные риски

1. Вероятностная модель может неверно интерпретировать смысл даже при правильных числах. Программные проверки и AI-проверка снижают риск, но не являются доказательством отсутствия галлюцинаций для любого набора. В ходе аудита реальные ошибки выявлялись живыми прогонами; один зелёный запуск не является универсальной гарантией.
2. Внешний сервис может вернуть перегрузку или некорректный ответ; после ограниченного числа исправлений показывается Error State с повтором. Нельзя выдавать такой сбой за отсутствие сведений в файле.
3. Ограничения MVP: первый лист Excel, до 4 МБ сериализованного запроса, 50 000 символов текста, 100 строк ответа. При большом каталоге для поиска могут понадобиться точные имена. Подробности — README.
4. `npm audit --omit=dev` не обнаруживает уязвимостей в production-зависимостях. Полный `npm audit` сообщает об уязвимостях инструментов Tailwind 3 (цепочки обработки glob/селекторов). Они обрабатывают доверенные исходники при сборке, а не пользовательские файлы. Автоматическое предложение миграции на Tailwind 4 не применено: это отдельная миграция стилей с риском изменения UI. Не заявлять «во всех зависимостях ноль уязвимостей».
5. У публичного MVP нет пользовательских квот и платежей; доступ к GigaChat ограничивается лимитами провайдера. Это не готовая коммерческая многопользовательская платформа.
6. Готового видео нет. До полной комплектации сдачи нужно записать и опубликовать ролик по сценарию.
