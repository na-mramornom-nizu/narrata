# Narrata

**Краткий анализ таблиц и текстовых отчётов с помощью ИИ.**

Загрузите CSV, Excel или вставьте текст — получите основной вывод, интерактивные графики и ответы на вопросы по данным. Регистрация не требуется.

[Открыть сервис](https://narrata-nine.vercel.app/)

## Возможности

- Загрузка CSV, XLSX и XLS через drag-and-drop или выбор файла; вставка текста.
- Основной вывод и 2–3 предложения с объяснением и контекстом источника.
- Интерактивные графики: модель выбирает представления, код рассчитывает табличные значения.
- Вопросы по источнику: поиск, сравнения, группировки, суммы и доли.
- Экспорт выводов, графиков и истории чата в PDF после завершения анализа.
- Индикатор загрузки, понятные сообщения об ошибках и повтор анализа.

Если запрошенных сведений нет в источнике, сервис отвечает: **«В этом отчете нет такой информации»**.

## Локальный запуск

Нужны **Node.js 22+**, npm и ключ авторизации GigaChat API.

```bash
git clone https://github.com/na-mramornom-nizu/narrata.git
cd narrata
npm ci
```

Скопируйте `.env.example` в `.env.local`:

```bash
cp .env.example .env.local
```

В PowerShell: `Copy-Item .env.example .env.local`.

Заполните переменные:

```dotenv
GIGACHAT_AUTH_KEY=ваш_ключ_авторизации
GIGACHAT_SCOPE=GIGACHAT_API_PERS
GIGACHAT_MODEL=GigaChat
```

`GIGACHAT_SCOPE` укажите в соответствии с доступом вашего проекта GigaChat. Ключ используется только в обработчиках API; `.env.local` исключён из Git. Не добавляйте ключ в переменные с префиксом `NEXT_PUBLIC_`.

```bash
npm run dev
```

Откройте [localhost:3000](http://localhost:3000). Другой порт можно задать командой `npm run dev -- --port 3001`. Без ключа интерфейс доступен, но анализ и ответы ИИ не работают.

## Пример для проверки

Откройте вкладку **«Вставить текст»** и вставьте учебный отчёт:

```text
Недельный отчёт команды разработки проекта «Аврора».
Из 50 задач 20 находятся на ревью, 10 в работе и 20 завершены.
На ревью приходится 40% задач.
В понедельник завершили 4 задачи, во вторник 6, в среду 10.
```

После анализа задайте вопрос: «В какой день завершили больше всего задач?» По тексту ответ — в среду, 10 задач. На вопрос «Какой бюджет проекта?» сведений в отчёте нет.

## Как устроено приложение

1. **Ввод.** Браузер разбирает файл, проверяет формат и размер, подготавливает колонки и строки. Вставленный текст сохраняется как исходный текст отчёта.
2. **Анализ — `/api/analyze`.** Код рассчитывает факты и варианты графиков по таблице. GigaChat определяет контекст и выбирает визуализации. Факты для нарратива охватывают все группы выбранной разбивки, включая не показанные на графике. Для подтверждённой концентрации суммарного показателя код связывает заголовок с рассчитанными долями; в остальных случаях текст пишет модель, затем выполняются проверки.
3. **Вопросы — `/api/chat`.** Модель предлагает план поиска или расчёта. Приложение проверяет поля и операции, затем выполняет расчёт на TypeScript или SQLite. SQLite работает в памяти отдельного потока с ограничениями ресурсов; разрешено только чтение данных.
4. **Текстовые отчёты.** Модель выбирает факты из исходных фрагментов. Проверяются ссылки на числа для графиков и подтверждающие цитаты для ответов чата.
5. **Экспорт.** PDF создаётся в браузере из текущего анализа и переписки.

Обработка анализа и чата выполняется двумя функциями Next.js на Vercel. Постоянная база отчётов и векторный индекс не используются. Данные передаются обработчикам приложения, а контекст запросов — GigaChat.

## Проверки и сборка

```bash
npm test                 # Автоматические тесты без запросов к модели
npm run typecheck        # Проверка TypeScript
npm run build            # Сборка приложения
npm start                # Запуск собранного приложения
```

Тесты проверяют разбор файлов, расчёты и процентные сравнения, ограничения SQL, текстовые факты, контекст нарратива и PDF. Для проверки качества ответов модели дополнительно используйте свой файл или учебный текст выше.

## Ограничения

| Ограничение | Значение |
| --- | --- |
| Форматы | CSV, XLSX, XLS и вставленный текст; в Excel читается только первый лист. |
| Размер файла | До 20 МиБ (20 971 520 байт). |
| Размер запроса | До 4 000 000 байт: данные после преобразования в JSON вместе с историей чата. Файл меньше 20 МиБ тоже может превысить этот лимит. |
| Вставленный текст | До 50 000 символов. |
| SQL-расчёт | До 8 секунд; выдача ограничена 100 строками. Суммы и количества рассчитываются до сокращения выдачи. |
| Графики | При недостатке числовых фактов графиков может быть меньше двух или не быть вовсе. |

Модель может неверно выбрать колонку или понять вопрос. Проверка чисел не обнаруживает все смысловые ошибки. Различия между группами сами по себе не подтверждают причины и не дают оснований для прогнозов.

Приложение не сохраняет отчёты между сессиями. Для сохранения результата используйте PDF. Данные обрабатываются внешним провайдером модели; отсутствие хранилища в приложении не означает отсутствие хранения у провайдера.

## Деплой на Vercel

1. Импортируйте GitHub-репозиторий как проект Next.js.
2. Добавьте `GIGACHAT_AUTH_KEY`, `GIGACHAT_SCOPE` и `GIGACHAT_MODEL` в настройки переменных окружения.
3. Выполните деплой. После изменения переменных окружения запустите новый деплой.

Текущий сайт связан с веткой `main`. `next.config.js` включает SQLite и CA-сертификат в сборку функций. Происхождение сертификата описано в [certs/README.md](certs/README.md).
