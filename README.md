# Narrata — AI-дашборды с нарративом

🔗 **Живой сервис:** https://narrata-твой-ник.vercel.app  
📦 **Исходники:** https://github.com/ТВОЙ_НИК/narrata

Загрузите CSV / Excel / сырой текст → получите AI-историю, авто-подобранные графики и чат по данным.

## Стек
- **Next.js 14** (App Router) — UI + serverless API
- **TypeScript**, **Tailwind CSS**, **Framer Motion** — «вайб 2026»
- **Recharts** — чистые минималистичные графики
- **PapaParse** + **SheetJS (xlsx)** — парсинг CSV/Excel
- **GigaChat API** (Сбер) — российская LLM, оплата в рублях, соответствие 152-ФЗ

## Запуск локально

```bash
npm install
cp .env.example .env.local
# заполните GIGACHAT_AUTH_KEY (см. ниже)
npm run dev
```

Откройте http://localhost:3000

Без `GIGACHAT_AUTH_KEY` таблицы анализируются локально по всем строкам. Чат работает в демо-режиме и отвечает только на вопросы о структуре; для свободных вопросов нужен ключ.

## GigaChat API

1. Зайдите в личный кабинет GigaChat Studio
2. Создайте проект → получите **Authorization key** (Client ID + Secret в Base64)
3. В `.env.local`:
   ```
   GIGACHAT_AUTH_KEY=ваш_ключ
   GIGACHAT_SCOPE=GIGACHAT_API_PERS
   GIGACHAT_MODEL=GigaChat
   ```

## Как это работает

1. **Ingest** (`lib/parse.ts`) — CSV/Excel → `{ rows, columns }`; текст → `{ rawText }`.
2. **Auth** (`lib/gigachat.ts`) — OAuth2 к `ngw.devices.sberbank.ru`, токен кэшируется в памяти до `expires_at`.
3. **Analyze** (`/api/analyze`, `lib/analysis-plan.ts`) — по всем строкам вычисляются факты и варианты визуализации: доли, различия групп, концентрация и динамика. GigaChat выбирает 2–3 подходящих графика, пишет заголовок с главным инсайтом и 2–3 предложения нарратива, затем проверяет текст по фактам. Значения графиков рассчитывает код, числовые утверждения сверяются с рассчитанными фактами. Линии доступны для временных данных; круговые диаграммы сохраняют полную сумму через сектор «Остальные». Если содержательно доступен только один график, отображается один. Пустые числовые ячейки не превращаются в нули, идентификаторы исключаются из показателей. При отсутствии ключа остается локальная базовая сводка.
4. **Render** (`lib/chart.ts` + `ChartCard`) — при наличии строк таблицы поле `data` модели игнорируется. Значения группируются из исходных строк; доступны сортировки по возрастанию и убыванию. Горизонтальные столбцы позволяют читать названия категорий.
5. **Ask** (`/api/chat`, `lib/table-query.ts`) — клиент передаёт историю. GigaChat раскрывает уточнения и возвращает ограниченный JSON-план: поиск, рейтинг, сумма/среднее/минимум/максимум/количество или разница двух записей. Сервер проверяет план и выполняет его по всей таблице; текст ответа собирается из вычисленных значений. Произвольный код модели не выполняется. Некорректный план получает одну попытку исправления. Для больших файлов каталог модели ограничен 40 000 символов строк и помечается как неполный; расчёты и поиск всё равно используют все исходные строки. Понимание формулировки и перевода названий зависит от модели; неоднозначные запросы требуют уточнения.

## Проверки

### Ответы и PDF

Ответы чата формулируются связными русскими предложениями для CSV, Excel и текстовых отчетов. Для таблиц модель переводит названия и согласует падежи; числа, единицы из заголовков и направление сравнения формирует код. Проверка схемы отделяет отсутствующие сведения от неоднозначного вопроса. При отсутствии данных ответ дословно: `В этом отчете нет такой информации`. Текстовые ответы дополнительно требуют цитат из источника.

Кнопка **Скачать отчёт в PDF** в шапке создает документ в браузере (pdfmake, встроенный Roboto с кириллицей). Она видна сразу, но доступна только после успешного завершения анализа. Он содержит источник и дату, нарратив, показатели, векторные графики с таблицами значений и всю историю чата, включая сообщения за пределами видимой области. Имя файла: `Narrata_Отчет_<источник>_<ГГГГ-ММ-ДД>.pdf`. Во время ответа чата кнопка недоступна, чтобы незавершенный ответ не потерялся. При смене датасета история сбрасывается.

### Обход TLS
GigaChat-эндпоинт подписан российским CA (Минцифры). Node его не знает, поэтому в `lib/gigachat.ts` выставляем `rejectUnauthorized: false`. Для прод-нагрузки — положить CA-файл и `NODE_EXTRA_CA_CERTS`.

### Контекст и ошибки ввода

Тема отчета определяется по имени файла, полям и примерам из разных частей таблицы. Она передается редактору нарратива и естественно вплетается в заголовок и текст без отдельного префикса. Каталоги описываются как записи об объектах, без предположений о количестве физических экземпляров.

CSV поддерживает UTF-8 и определение распространенных Windows-кодировок, составные заголовки опросов и второй ряд русских названий полей открытых данных. Неправильные кавычки, число ячеек, пустой файл и бинарное содержимое дают понятное сообщение с действием. Сбой ИИ сохраняет разобранный файл для повторного анализа; технические детали остаются на сервере. Подсказка «Новый датасет» объясняет сброс отчета и чата.
