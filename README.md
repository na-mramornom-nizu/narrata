# Narrata

AI-дашборд из CSV, Excel или текстового отчёта: главный инсайт, графики и чат по данным.

- [Живой сервис](https://narrata-nine.vercel.app/)
- [GitHub](https://github.com/na-mramornom-nizu/narrata)
- [Проверка по заданию](docs/MVP-VALIDATION.md)
- [Сценарий видео на 3–5 минут](docs/VIDEO-PITCH.md)

## Запуск

Нужны Node.js 22+ и ключ GigaChat. Вход пользователей и база данных не требуются.

```bash
npm ci
cp .env.example .env.local
# Укажите GIGACHAT_AUTH_KEY в .env.local
npm run dev
```

В PowerShell вместо `cp` можно использовать `Copy-Item .env.example .env.local`.
Откройте [localhost:3000](http://localhost:3000). Другой порт: `npm run dev -- --port 3001`.

Переменные окружения:

| Переменная | Назначение |
| --- | --- |
| `GIGACHAT_AUTH_KEY` | Ключ авторизации GigaChat, только на сервере |
| `GIGACHAT_SCOPE` | Область доступа, по умолчанию `GIGACHAT_API_PERS` |
| `GIGACHAT_MODEL` | Модель, по умолчанию `GigaChat` |

Без ключа приложение показывает понятную ошибку подключения ИИ. Вымышленных демо-графиков и подмены AI-нарратива сухой статистикой нет.

## Стек

Next.js 15 / React 18 / TypeScript; Tailwind CSS и Framer Motion; Recharts; PapaParse и SheetJS; GigaChat; sql.js для расчётов; pdfmake для экспорта.

SheetJS установлен из [официального источника](https://docs.sheetjs.com/docs/getting-started/installation/nodejs/): npm-версия пакета устарела. Версии и контрольные суммы зафиксированы в `package-lock.json`.

## Устройство

1. **Ввод:** `lib/parse.ts` разбирает CSV/XLSX/XLS в браузере. Текст передаётся без преобразования. Ошибки формата показываются до анализа.
2. **Нарратив:** `lib/analysis-plan.ts` рассчитывает факты и варианты графиков по всем строкам. ИИ выбирает визуализации и пишет 2–3 предложения. Числа проверяются по фактам. `lib/text-analysis.ts` проверяет структуру текстового отчёта и цитаты, подтверждающие числа графиков.
3. **Чат:** ИИ выбирает поля, фильтры и операции. `compute-query.ts` строит формулы, `table-query.ts` обрабатывает простые запросы. Составные вычисления выполняет read-only SQLite в изолированном worker с ограничением времени/памяти. База существует только на время запроса, отдельный сервер БД не нужен.
4. **Ответ:** код подставляет рассчитанные числа; процентное сравнение сохраняет базу и направление. Отсутствующие сведения: `В этом отчете нет такой информации`. Неоднозначный вопрос и сбой сервиса имеют отдельные сообщения.
5. **UI:** `app/page.tsx` управляет состояниями, `components/` содержит загрузку, нарратив, графики, чат и скелетоны. PDF создаётся в браузере после анализа и содержит графики, выводы и весь чат.

API: `POST /api/analyze` принимает Dataset, `POST /api/chat` — `{ dataset, messages }`. Это две serverless-функции Next.js; авторизации пользователей, векторной БД, фоновых очередей и отдельного бэкенда нет.

## Проверки

```bash
npm test
npm run typecheck
npm run build
npm audit --omit=dev
```

Интеграционные прогоны требуют запущенного сервера, ключа и расходуют токены GigaChat:

```bash
node --require ./tests/register.cjs tests/countries.live.cjs D:/countries.csv http://localhost:3001
node --require ./tests/register.cjs tests/comparisons.live.cjs D:/ http://localhost:3001
node --require ./tests/register.cjs tests/mvp.live.cjs http://localhost:3001
```

Последние два сценария используют локальные тестовые файлы из описания задачи. Пользовательские датасеты и ключи в репозиторий не включены. Запускайте live-прогоны последовательно, чтобы не превышать лимиты провайдера.

## Ограничения MVP

- Excel: анализируется первый лист. CSV: UTF-8 и распространённые Windows-кодировки.
- Файл до 20 МБ на этапе чтения; фактический JSON-запрос с данными и чатом — до 4 МБ. Ограничение проверяется до отправки с запасом относительно [лимита Vercel 4,5 МБ](https://vercel.com/docs/functions/limitations). Текст — до 50 000 символов.
- Расчёты используют все загруженные строки. Каталог для модели содержит схему, статистику, значения небольших категорий и ограниченную выборку записей. Поиск редких сущностей в больших файлах может потребовать точного имени/кода.
- Вывод чата ограничен 100 строками. Пропуски не равны нулям; деление на ноль не вычисляется. Статистика: генеральная дисперсия, корреляция Пирсона, линейная интерполяция перцентилей.
- Обычно 2–3 графика. Если численных данных недостаточно, показывается меньше: графики ради количества не выдумываются.
- Проверки чисел и цитат снижают риск галлюцинаций, но не доказывают правильность любой семантической интерпретации. Причинность и прогнозы не следуют автоматически из файла.
- Данные живут в памяти страницы и запросов, после перезагрузки не сохраняются. Для анализа контекст передаётся GigaChat. Не загружайте данные, которые нельзя передавать этому провайдеру.

## Деплой

Импортируйте репозиторий в Vercel и задайте переменные из `.env.example`. Production branch — `main`. В этом проекте push в `main` запускает публикацию.

Сертификат GigaChat включён в serverless-сборку; проверка TLS включена. Происхождение сертификата — в [certs/README.md](certs/README.md). SQL-runtime также включён в сборку явно через `outputFileTracingIncludes`.

Видео ещё требуется записать и разместить на Loom/Vimeo. Сценарий — материал для записи, не ссылка на готовый ролик.
